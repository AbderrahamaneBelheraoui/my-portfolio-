Project Description
This project is a personal portfolio website built for the Web Development lab. It presents my profile as a Systems Security student, along with my technical skills and recent projects. The website uses a dark theme, works well on both computers and mobile phones, and includes a simple admin panel where you can add, update, and remove projects and skills directly in the browser.

---

 Technologies Used
- **HTML5:** Page structure, semantic tags, and meta tags.
- **CSS3:** Dark theme design, CSS Grid and Flexbox for responsive layout, and smooth animations.
- **JavaScript (Vanilla JS):** Dynamic content rendering, scroll animations, and interactive forms.
- **External Resources:** Google Fonts (`Outfit`, `Space Grotesk`) and FontAwesome icons.

---

Implemented Features
- **Responsive Navigation:** Smooth scrolling between sections and a mobile hamburger menu.
- **Hero & About Sections:** Personal introduction, education level, and focus areas.
- **Dynamic Projects Showcase:** Projects are loaded and displayed using JavaScript.
- **Interactive Skills Bar:** Animated progress bars that fill up when you scroll to the skills section.
- **Admin Mode (CRUD):**
  - Protected by a simple password prompt (`admin123`).
  - Add, edit, and delete projects (title, category, image, tech stack, description).
  - Add, edit, and delete skills with custom proficiency percentages.
- **Contact Section:** Clickable links for email, phone, location, GitHub, and LinkedIn.
